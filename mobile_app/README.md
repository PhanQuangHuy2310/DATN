# Mobile App — P1, chưa triển khai

P0 là responsive web tiếng Việt và cần mạng. Flutter/mobile native, offline approval, biometric signing và push notification không thuộc baseline P0.

Không mô tả module này là đã triển khai. Khi có business case P1, phải thiết kế lại session/device trust, secure storage, revoke, deep link, push privacy, offline conflict và test accessibility trước phát triển.
