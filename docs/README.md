# Sơ đồ kỹ thuật

Thư mục này giữ các nguồn Mermaid có thể chỉnh sửa cho kiến trúc và workflow EAS. Tài liệu báo cáo, ảnh trích xuất và bộ đặc tả nguồn không nằm trong repository ứng dụng.

- [Nguồn sơ đồ và hướng dẫn xuất](./diagrams/README.md)
- Sơ đồ use case, activity, sequence, state machine và architecture/data nằm trong `diagrams/`.

Chỉnh Mermaid source thay vì sửa ảnh đã render. Hành vi ứng dụng và quyền truy cập phải dựa trên API implementation và database contract.
